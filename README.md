# Sanaseppä

Sanaseppä on suomalainen sanapeli, jossa etsit viisi-, kuusi- tai seitsemänkirjaimista sanaa. Voit pelata yksin, ratkoa päivän sanan tai haastaa ystävät samaan huoneeseen.

**[Pelaa Sanaseppää](https://rasse2009.fi/sanaseppa/)** · [Sanaseppä Flash](https://rasse2009.fi/sanaseppa/flash/) · [Numeroseppä](https://rasse2009.fi/sanaseppa/numeroseppa/)

## Tämä repository

Tämä on Sanasepän **julkinen esittelyrepository**. Se sisältää staattisen esittelysivun ja yleiskuvauksen. Varsinainen peli toimii yllä olevassa osoitteessa.

Pelilogiikkaa, PHP-palvelinkoodia, käyttäjätietoja tai palvelimen yksityiseen kansioon tallennettavia pelitietoja ei julkaista tässä repositoryssa.

## Esittelysivu

Sivu toimii suoraan avaamalla `index.html` selaimessa. Se voidaan julkaista GitHub Pagesissa: **Settings → Pages → Deploy from a branch → `main` → `/ (root)`**. Tällöin osoite on [rassetin.github.io/sanaseppa-public](https://rassetin.github.io/sanaseppa-public/).

Pelin virheistä ja kehitysideoista voi kertoa [Issues-osiossa](https://github.com/Rassetin/sanaseppa-public/issues). Älä lisää ilmoituksiin salasanoja tai muita yksityisiä tietoja.
